# 纯InSAR建筑高度先验独立性审计（2026-08-24）

## 结论

当前同济SAR数据、建筑矢量和GAMMA干涉栈不足以在完全不使用建筑先验高度的条件下，稳定恢复全区建筑绝对高度。现有 `picall/17_屋顶核心区SBAS建筑高度分布.svg` 的238栋结果使用了先验高度进行屋顶R-D定位和整周初始化，只能视为先验辅助残差估计，不能作为先验独立的InSAR建筑高度产品。

本轮没有用任何纯InSAR失败分支覆盖正式图片，也没有为无解建筑填入先验值。

## 修正的实现问题

1. 平均相干性曾只对已经超过0.55的干涉对求均值，造成质量虚高。现已改为对全部有限干涉对求均值，超过0.55的数量单独统计。
2. 旧 `gamma_native_ipta_sbas_full71/ipta/pairs.itab` 实际只有17条记录，却被摘要记为71对。本轮从71条真实干涉对重建了点栈。
3. 局部地面参考曾先查询全部地面点，再删除GAMMA未接受点，可能误报无附近参考。现改为先筛选GAMMA有效地面，再建立最近邻树。

## 为什么屋顶像素不足以完全先验独立估高

屋顶核心像素可以提供稳定相位，但平顶屋顶内部近似等高，缺少从地面到屋顶的连续空间相位梯度。每条干涉对仍含未知的整周常数。多基线搜索在当前噪声、叠掩和网络结构下存在多个相位代价相近的高度别名；低相位残差不能证明绝对高度分支正确。

原始MATLAB用建筑孤岛内的高程 `max-min` 抵消共同整周常数，但同济数据中通过相干性筛选的孤岛主要由离散屋顶、地面或叠掩散射点组成，没有稳定覆盖完整立面，因此高度跨度仍明显压缩。

## 若必须保持先验独立，需要新增的信息

至少需要下列一种独立观测来确定绝对高度整周分支：

1. 不同视向的升降轨SAR或不同入射角影像；
2. 可识别屋顶—地面对应关系的高分辨率SAR/层析SAR；
3. 少量独立实测控制建筑，仅用于全局整周/系统误差标定；
4. 外部DSM或激光雷达屋顶高程作为独立验证/定标数据。

在没有新增观测且禁止先验影响整周选择时，科学上合理的输出是“无可靠绝对高度解”，而不是继续选择看起来接近先验的相位分支。
