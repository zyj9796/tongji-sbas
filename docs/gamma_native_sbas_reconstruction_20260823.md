# 同济建筑高度 GAMMA 原生 SBAS 重建记录（2026-08-23）

## 1. 本轮结论

当前结果差并非制图问题，而是旧主流程没有完整执行 GAMMA SBAS，并且存在先验泄漏。现已跑通以下 GAMMA 原生链：

`SLC_intf → phase_sim_orb → sub_phase → adf → multi_def_pt → mb_pt → 局部稳定地面相减 → 单体稳健聚合`

该链已经替换旧的 Python 整周搜索和 Python LGR 主流程，但当前数值仍不能作为最终建筑高度。剩余主瓶颈是：论文要求的“矢量隔离单体建筑局部解缠”尚未在 GAMMA MCF 网络中逐栋实现。现有 `multi_def_pt` 是全点集、多补丁求解，不能等价替代论文的单体孤岛网络。

## 2. 论文方法与 GAMMA 命令对应

论文第 3、4 章给出的核心顺序为：

1. 配准精度优于 0.1 像元；
2. 用外部低分辨率 DEM 去除平地和主要地形相位；
3. 自适应滤波；
4. 建筑矢量经 R-D/2D LUT 投影到雷达坐标；
5. 形态学和 DBSCAN 形成独立建筑孤岛；
6. 孤岛内部按相干性和振幅离差构建局部抗差网络并独立解缠；
7. 以 `DA < 0.4`、平均相干性约 `0.75` 筛选可靠点；
8. 每个建筑至少 12 对有效干涉观测；
9. 用含形变项和 DEM 高程误差项的多主影像观测矩阵求解；
10. 逐栋使用 1.5×IQR 剔除离群值，再取中位数。

本地 GAMMA 2021 对应关系：

| 任务 | GAMMA 实现 |
|---|---|
| 基线构网 | `base_calc` |
| 干涉图 | `SLC_intf` |
| 轨道/参考面模拟相位 | `phase_sim_orb` |
| 差分相位 | `sub_phase` |
| 自适应滤波和相干性 | `adf` |
| MCF 解缠 | `mcf` |
| IPTA 点栈 | `SLC2pt`, `intf_pt`, `phase_sim_orb_pt`, `sub_phase_pt` |
| 初始多基线整周与高程/形变模型 | `multi_def_pt` |
| GAMMA SBAS 时序与高程改正 | `mb_pt` |
| 精密基线试验 | `base_ls_pt` |

特别注意：`multi_def_pt` 不是完整 SBAS 的终点。GAMMA 手册把 `mb/mb_pt` 定义为从多主影像解缠差分相位生成时序，并联合估计高程改正的程序。

## 3. 已纠正的错误

### 3.1 先验 DSM 泄漏

旧链使用 `work/gamma_sbas/dem/20200708_dsm_rdc.hgt` 作为参考高程，再计算“参考高程 + 残差 − 4 m”。该栅格统计为 P95=25 m、最大值=106 m，已包含建筑先验高度。因此即使没有对 NaN 补值，也仍属于把先验高度注入结果。

新链只使用空间常数 4 m 作为 GAMMA 非空相位基准，并从同一 GAMMA 解中计算“建筑候选点高程 − 邻近稳定地面高程”。常数项严格抵消。

### 3.2 差分和滤波顺序

旧链为 `SLC_intf → adf → sub_phase`，会先滤波完整地形条纹，再扣除模拟相位。新链改为 `SLC_intf → phase_sim_orb/sub_phase → adf`，即先获得差分干涉图，再滤波。

### 3.3 `SLC_diff_intf` 兼容性

安装的 GAMMA 2021 对本项目 TSX `SCOMPLEX` 裁剪数据运行 `SLC_diff_intf` 时输出全零。禁用频谱滤波仍为全零。采用手册给出的等价链 `SLC_intf + sub_phase` 后输出正常，因此不再使用该故障命令。

### 3.4 共同配准参考

所有 RSLC 共同配准到 `20200708`。`phase_sim_orb` 现显式传入 `data/tongji_rslc/20200708.rslc.par`，避免把非像对主影像作为几何参考。

### 3.5 SBAS 程序缺失

旧链把自写 LGR 或 `multi_def_pt` 初解称为 SBAS。现已追加 `mb_pt`，由 GAMMA 生成多主影像时序、相位残差和高程改正。

## 4. 先验高度使用边界

纯 InSAR 分支中的建筑矢量 `height` 字段：

- 不用于干涉图生成；
- 不用于点筛选；
- 不用于整周模糊度选择；
- 不用于 Gamma/SBAS 参数估计；
- 不用于阈值选择和质量控制；
- 不用于缺失值填充；
- 只在 GAMMA 解冻结后合并，计算相关性、MAE 和差值作为独立旁证。

现有 GAMMA 投影产品在几何构造阶段使用先验高度拉伸建筑体，这是此前用户明确指定的投影初始化规则；它不向高程解算值写入先验数值。第 11 节进一步记录用户授权的“先验屋顶位置/整周初始化 + GAMMA `mb_pt` 残差反演”混合分支。该分支不得称为纯 InSAR，也不得用与同一先验的差异作为独立精度或调参依据。

## 7. 当时提出的下一阶段假设（已在第8节完成检验）

1. 对每栋建筑构建“完整投影支持带 + 邻近稳定地面锚点”的独立局部掩膜；
2. 每一干涉对在该局部掩膜上运行 GAMMA `mcf`，使用相干性权重和 Delaunay 模式；
3. 保持地面锚点一致，消除单体局部零相位规范自由度；
4. 将逐栋 GAMMA 解缠相位栈送入 `mb_pt`；
5. 用留一干涉对、相位闭合、跨时段重复性和建筑内屋顶簇 IQR 进行盲选；
6. 只有通过内部验收后，才计算与先验高度的对比；
7. 未通过的建筑保持无解，禁止任何先验填充。

## 8. 逐栋解缠与 GAMMA SBAS 优化续验

新增程序：`code/reproduce_tongji/run_gamma_building_mcf_sbas.py`。该程序逐栋构造“建筑投影支持点 + 邻近稳定地面点”，支持多种解缠诊断分支，并在每栋局部点集上运行 GAMMA `mb_pt`。所有分支均先完成 InSAR 内部筛选，最后才读取矢量 `height` 做旁证；无解或拒绝建筑始终为空。

### 8.1 被否证的局部解缠方案

以不依赖先验选择的 658 号大样本建筑进行端到端试验：

| 初始解缠 | 高度 | 相位残差 | 判定 |
|---|---:|---:|---|
| 全局 `multi_def_pt` 相位 + 逐栋 `mb_pt` | 21.26 m | 0.96 rad | 保持跨基线整周尺度 |
| 逐栋 `mcf_pt` 从 wrapped phase 直接解缠 | 8.88 m | 1.19 rad | 屋顶—地面大相位跳变被空间平滑，拒绝 |
| 逐栋 `multi_def_pt` 从 wrapped phase 重新搜索 | 4.38 m | 0.36 rad | 选择低高度局部极小值，拒绝 |
| 全局模型 + 逐栋残差 `mcf_pt` | 18.88 m | 1.05 rad | 25 栋盲样本无一致改善，拒绝 |
| 全局已解缠相位 + 逐栋二次 `multi_def_pt` | 2.82 m | 0.34 rad | 局部自由度吸收高度，拒绝 |
| ZJC 9邻域/4-KNN/Bisquare/LSMR + GAMMA `mb_pt` | 3.63 m | 0.13 rad | 图积分零相位规范吸收绝对高度，拒绝 |

这些试验说明：低相位残差并不自动表示建筑高度正确。对于屋顶相对地面的绝对高度，必须先由跨基线时序模型固定整周分支；从零开始的单体空间解缠只适合论文中的建筑内部相对高程范围，不能直接替代屋顶绝对高度反演。

### 8.2 `mb_pt` 平滑与观测权重

- 固定 25 栋盲样本中，`mb_pt gamma=100` 相比 `gamma=10` 将相位残差中位数由 0.603 rad 降至 0.307 rad，高度中位数基本稳定（17.94 m 对 17.89 m），并多通过 1 栋。GAMMA 手册将 `gamma=100` 解释为近线性形变约束，因此当前建筑高度分支采用 `gamma=100`。
- 已实现按稳定地面残差 MAD 生成 GAMMA 三列 `sigma` 文件，并完成加权 `mb_pt`。全区残差由 0.699 rad 降至 0.650 rad，但高度中位数由 11.30 m 降至 10.74 m，负高尾部未消除，因此只保留为诊断，不替代当前分支。

### 8.3 当前两类全区产品

工程稳健屋顶核心分支：

- 屋顶核心掩膜；
- 全局 GAMMA `multi_def_pt` 只负责跨基线整周初始化；
- 每栋独立 GAMMA `mb_pt(gamma=100)`；

- 文件：`results/tables/tongji_building_height_gamma_roofcore_buildingmb_gamma100_insar_only.csv`。

论文严格聚合分支：

## 9. 闭合校正与原代码稠密孤岛续验

37 对、22 景网络连通，但边连通度仅为 1，含 7 条桥边和 16 条冗余弦边。`correct_gamma_punw_closure.py` 固定稳定地面最大相干生成树，只对弦边逐点施加整数 `2π` 校正。51,216 个有效点中 24,376 个被修正，最大 2 周；三角闭合异常降至 56 点（约 0.11%）。完整屋顶核心分支得到 299 栋、相位残差中位数 0.291 rad，但高楼尺度仍被压缩，因此闭合误差不是主瓶颈。7 条桥边没有闭合环可审计，保持原值。

`simulate_gamma_height_sensitivity.py` 用 `phase_sim_orb_pt(104 m)-phase_sim_orb_pt(4 m)` 除以 100 m，得到每对、每点的单位高度相位灵敏度；采用 `ph_flag=1` 避免巨大椭球相位的 FLOAT 相消误差。中位绝对灵敏度为 0.1166 rad/m，与约 54 m 的中位高程模糊度一致。

共同屋顶高度搜索和高度—位置耦合搜索均未通过：固定 25 栋中，共同高度分支虽把残差降至 0.177 rad，却把高度中位数降到 11.73 m，事后先验相关性为负。低残差只是错误低高度极小值。

论文第 4.1.2 节使用完整建筑孤岛内的像元高程改正，IQR 后取中位数，并未限定屋顶；ZJC 原始 `main_hight.m` / `multihight.m` 实际使用 `max(heightMatrix(:))-min(heightMatrix(:))`。此外，原 `unwrap_phase_matrix.m` 把外接矩形全部像元纳入 KNN 网络，掩膜外相位置零，这与论文“仅孤岛内部”不完全一致，并可能引入背景偏置。

`run_zjc_dense_island_gamma_sbas.py` 分别测试了仅岛内有效像元、原代码外接矩形零背景模式、ZJC 两参数直接解、GAMMA `mb_pt`，以及论文的 `|B⊥|=30–250 m、dt≤44 d` 网络。45 号建筑在 37 对网络中的稳健内部跨度仅约 7.3–7.7 m，ZJC 直接解与 GAMMA 基本一致；论文阈值获得 27 对但分裂成 10 个不连通分量，跨度进一步降至约 2.8–2.9 m。高度衰减已发生在局部解缠相位场，而非 GAMMA SBAS 吸收。

全局 GAMMA 解中，45 号存在一个约 50.2 m 的候选点；它的早/晚时段拟合为 61.8/58.9 m，长/短基线拟合为 59.5/59.2 m。但它是单点高度簇，无法与稳定整周别名区分。`select_stable_roof_top_points.py` 对全区执行冻结的跨子集稳定性规则并取最高候选，得到 332 栋、P95 82.3 m；事后先验相关性仅 0.112、MAE 14.86 m，因此该产品被否决，45 号只保留为候选散射点。

## 10. 当前判断

1. 现有单轨数据无法仅凭单个稳定 PS 点可靠判定高楼整周分支；子集稳定性不能排除一致别名。
2. 论文 IQR+中位数要求同楼拥有足够多同高可靠点，同济高楼常只有一个顶部候选，前提不成立。
3. 原代码完整孤岛跨度也未恢复真实尺度，且含外接矩形零背景缺陷。
4. 本阶段结论当时是不更新图 17；该限制已被第 11 节通过严格混合分支后的新制图结果取代。仍禁止把未通过门控的数值写入矢量或用 `height` 填充。
5. 继续提升可信度需要新的独立约束：更多高质量长基线像对、另一轨向/视角，或 LiDAR/实测控制点；继续放宽统计规则只会把整周别名包装成高楼结果。

## 11. 先验屋顶整周初始化与 GAMMA `mb_pt` 闭环续验

用户进一步明确：`clean_equal_height` 的 `height` 可用于建筑体拉伸、屋顶 R-D 定位和粗高度初始化，但绝不能用于无解填充。为此新增：

- `build_prior_roof_cycle_initialization.py`：只保留 GAMMA 投影后、腐蚀一像素且无跨楼冲突的屋顶核心 PS；先验高度只写入“相位整周初始化表”，该表不是高度结果；
- `search_geometry_constrained_wrapped_height.py`：在每个 PS 的 R-D 可行高度区间内诊断包裹相位模糊度；
- `run_gamma_building_mcf_sbas.py --unwrap-engine geometry_wrapped_init`：用初始化值确定每对干涉相位的整数周数，随后由 GAMMA `mb_pt` 重新估计高程改正、形变时序和残差；局部稳定地面从同一 `mb_pt` 解中相减；
- 所有该分支产品均标记 `insar_only=false`、`filled_from_prior=false`，无解建筑保持空值。

### 11.1 宽 R-D 可行区间诊断被否决

逐点包裹相位搜索共检查 7,616 个稳定 PS，7,573 个在圆周代价 0.90 下通过，说明该阈值筛选力不足。31.2% 的通过点落在其几何高度区间下边界；最大重复簇经 `mb_pt(gamma=100)` 后得到 287 栋，高度中位数 10.11 m、P95 25.36 m；最高重复簇得到 287 栋，中位数 10.62 m、P95 32.13 m。两者仍发生低高度模糊度吸附，均拒绝。

45 号楼在宽区间诊断中形成 10 点高层簇，GAMMA `mb_pt` 最终得到约 52.72 m，但宽区间全区规则不稳定，因此不能只凭该个案接受。

### 11.2 严格先验屋顶核心 + GAMMA SBAS

初始 GAMMA 校正投影的腐蚀屋顶核心包含 45,046 个 IPTA 屋顶点、604 栋建筑，其中 573 栋至少有 4 点。先验高度只决定初始屋顶位置和 `2π` 周数；最终高度来自 GAMMA `mb_pt`，不把先验值原样复制到结果。

宽松首轮（至少 4 点，`gamma=100`）结果：

- 604 栋候选，495 栋完成 GAMMA 数值解，482 栋通过；
- 高度中位数 18.43 m，P05/P95 6.36/42.59 m；
- 相位拟合残差中位数 0.325 rad；
- 文件：`results/tables/tongji_building_height_prior_roof_init_gamma100.csv`。

论文严格首轮在点级施加平均相干性 `>=0.75`，要求至少 4 个屋顶 PS、建筑相位残差中位数 `<=0.75 rad`、屋顶高度 IQR `<=8 m`，并采用 IQR 后中位数：

- 490 栋候选，359 栋完成 GAMMA 数值解，319 栋通过；
- 高度中位数 18.82 m，P05/P95 6.70/42.21 m；
- 相位拟合残差中位数 0.308 rad；
- 45 号楼的屋顶点中位相干性为 0.737，未通过点级相干性 `>=0.75` 的严格产品；其 52.74 m、残差 0.343 rad 仅保留在宽松首轮中作为混合候选；
- CSV：`results/tables/tongji_building_height_prior_roof_init_gamma100_paper_strict.csv`；
- 含全部 1,028 栋几何、仅对 319 个有解建筑写数值的矢量：`results/geodata/tongji_building_height_prior_roof_init_gamma100_paper_strict.geojson`。

### 11.3 阻尼 R-D 迭代被否决

用首轮 482 个解以 `alpha=0.6` 更新投影，GAMMA `coord_to_sarpix` 重新投影 11,863 个三维顶点。训练/验证时相独立得到一致的全局残差位移（行 -2、列 -9）；仅 194/1,028 栋局部边缘修正在两组时相中同时通过。

## 13. 基于多时相 SAR 图像特征的投影残差校正

为避免仅依赖 GAMMA 轨道几何后仍残留少量像素级错位，新增 `refine_gamma_projection_with_sar_features.py`。该程序不重新解释建筑高度，而以 GAMMA R-D 屋顶投影为物理初值，对各时相幅度先执行对数压缩、稳健归一化、局部直方图均衡和有限反锐化，再从 Scharr 梯度与 Canny 支持中构造建筑结构特征图。

全部时相按日期交替冻结为训练组与留出验证组。校正分两级：

1. 小范围全局仿射只在训练、验证特征得分均提高时接受。本次候选未通过验证门控，因此自动回退为恒等变换，没有扭曲 GAMMA 整体几何；
