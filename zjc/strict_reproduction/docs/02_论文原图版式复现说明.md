# 论文原图版式复现说明

更新时间：2026-08-25

## 输出范围

输出目录：`results/paper_figure_reproduction/`。

本轮按论文原图的面板数量、纵横比例、图层顺序和主要配色，逐张输出 14 个独立中文 SVG：图 3.1—3.10、图 4.1、图 4.2、图 4.8、图 4.9。遵照要求，不输出图 3.11 以及图 4.3—4.7 等误差统计类图。每张图是单独文件，不制作拼图文件。

## 数据与方法对应

- 图 3.1、3.2、3.3、4.1：用 Python 矢量元素重新绘制，文字可编辑，没有使用低分辨率截图。
- 图 3.4、3.7、3.8、3.9、3.10、4.2：背景来自 2023-10-07 单景 10000×7000 SAR 幅度；局部图使用原始像元分辨率或 2 倍抽样的高清嵌入栅格。
- 图 3.5：由论文结果对应的 48 干涉对 `paper_result_48.bperp` 直接绘制。
- 图 3.6：地理坐标建筑来自天津建筑轮廓；雷达坐标建筑来自 GAMMA 几何投影栅格。`Floor` 只用于复现论文的候选建筑/楼层分组展示，不参与高程反演或填充。
- 图 3.8—3.10：使用 2024-05-14/2024-06-05 代表性干涉对，展示滤波缠绕相位、覆盖式 MCF 对照和逐建筑独立 GAMMA-MCF。因为流水线没有保留论文意义上的整幅传统全局 MCF 栅格，图中没有将覆盖式对照冒充为全局 MCF。
- 图 4.2：上图为固定远距侧物理参考的独立 MCF+SBAS 像元结果；下图为任意首像元零点对照，二者都来自实际计算产品。
- 图 4.8：论文使用的 GBA 和 CNBH-10 m 外部高度产品未随数据提供。前两行仅严格复现论文版式并明确标注缺失，未生成虚假高度；第三行使用本次 GAMMA-MCF+SBAS 结果。
- 图 4.9：灰色低层建筑只用统一示意高度形成城市白模，橙色高层采用本次 SBAS 有解值；未把 `Floor` 或其他先验高度填入反演结果。

## 清晰度与格式检查

- 所有正式输出均为 SVG，没有生成正式 PNG/PDF。
- SAR 与密集点图层以高清 PNG 数据流嵌入 SVG，避免数百万矢量点造成浏览器卡顿；轴、图例、标注和流程图保持矢量。
- `svg.fonttype=none`，中文文字保持文本形式。
- 14/14 文件通过 XML 解析；14/14 文件通过 CairoSVG 1200 像素宽渲染检查。

### 字体与重叠修正（2026-08-25）

- 全部文字统一为系统实际安装的 `Noto Sans CJK SC`，SVG 中不再声明多级字体回退，避免中文、数字和符号在不同查看器中出现字形混排。
- DBSCAN 图中的希腊字母 ε 改为普通 Unicode 文本，不再由数学排版引擎拆分为多个字体片段。
- 图 3.6、3.8、3.9、3.10 和 4.2 的子图说明由坐标轴下方移至图框左上角，消除了与横轴标题的重叠。
- 图 3.5 日期刻度旋转至 72°、缩小至 5.5 pt，并增加底部留白。
- 修正后 14/14 SVG 仅含一个字体族，并再次通过 1400 像素宽逐图渲染检查。
