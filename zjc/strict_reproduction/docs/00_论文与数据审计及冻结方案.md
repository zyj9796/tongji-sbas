# 论文与数据审计及冻结方案

更新日期：2026-08-25

## 1. 复现目标

在天津论文原研究区内，从 21 期原始复数 SLC 开始，重新完成条带拼接、裁剪、精配准、干涉构网、差分干涉、DEM 地形相位去除、建筑矢量 R-D/2D LUT 映射、建筑孤岛提取、独立分区解缠、SBAS 高程反演、建筑级 IQR 清洗与中位数聚合，并复现论文中可由现有输入验证的图件和统计量。

“严格复现”分为三个不可混淆的层级：

- **论文正文主线**：正文明确给出的模型、阈值和步骤，是正式结果的依据。
- **论文结果一致分支**：正文内部冲突时，采用能产生论文明确宣称的样本数或图表结构的参数组合。
- **原代码审计分支**：逐项运行或重构原 MATLAB，用于说明正文与代码差异，不替代正文主线。

## 2. 已核实输入

### 2.1 SAR 数据

- 115 个 ZIP，共约 70.53 GiB；21 个日期，日期范围为 2023-10-07 至 2024-06-05，重访间隔 11 天。
- 产品名为 `BC3-SM-SLC-1SVV-*`，降轨、左视、VV、条带模式、斜距复数影像。
- 单段影像为 12426 距离向样本 × 14022 方位向行，复数整数 GeoTIFF。
- 元数据给出的距离向像素间距为 1.249135 m，方位向像素间距为 1.790613 m，雷达频率约 5.4000001 GHz，中心入射角约 37.62°，与论文所述 1.25 m、1.79 m、C 波段相符。
- SAFE 清单中保留了 `SENTINEL-1`/`S1B` 和 Sentinel-1 IPF 等模板字段，但产品名、轨道号、条带模式、像元参数和实际星历属于本数据。不能把模板任务名当成真实 Sentinel-1 数据，也不能套用 TOPS burst 流程。
- 论文中心点为 117.21002778°E、39.12663889°N。该点位于相邻两段条带的共同覆盖区，论文约 10000×7000 像元主裁剪需要每期拼接相邻两段，不能仅使用单个 ZIP。
- 2023-10-07 的 `000017/000020` 与 2023-10-29 的 `000017/000019` 是重复产品：对应测量 TIFF 的尺寸和 CRC 完全一致。正式输入每组只保留一个逻辑记录，原 ZIP 不删除。

### 2.2 建筑矢量

- `天津.shp` 为 EPSG:4326，共 154051 个 Polygon。
- 属性为 `Id` 和 `Floor`；数据时间早于 SAR，需记录新增/拆除建筑造成的掩膜不一致。
- 主实验区只裁剪相交建筑；原始矢量保持只读。

### 2.3 DEM

- 论文明确写明使用 SRTM DEM，因此选用 SRTM 1 Arc-Second Global（约 30 m），研究区只需 `N39E117`。
- 水平基准为 WGS84；高程单位为米，垂直基准为 EGM96。GAMMA DEM 参数文件必须明确这一基准，不能把 EGM96 正高无说明地当成 WGS84 椭球高。
- DEM 的作用限定为生成 LUT、模拟/扣除地形相位和提供建筑地面绝对高程。它不是建筑高度先验。

## 5. 冻结处理链

### A. 输入与拼接

1. 解析全部 ZIP 的 manifest、annotation、calibration 和 TIFF CRC，生成不可变清单。
2. 每期选取覆盖主裁剪区的相邻两段；重复产品按 TIFF CRC 去重。
3. 用 `par_S1_SLC` 导入条带 SLC。虽然产品沿用 SAFE/S1 XML 结构，但不生成 TOPS 参数、不执行 TOPS 专用配准。
4. 利用重叠区估计二维偏移和相位/增益差，以 `SLC_cat` 拼接；拼接缝两侧做幅度与相位连续性 QA。
5. 在参考景拼接影像上冻结 10000×7000 整像元裁剪，再对全部日期使用同一物理窗口。

### B. 精配准与干涉预处理

1. 选择时间居中、覆盖完整且质量稳定的主影像；同时保存以 2023-10-07 为主影像的论文/原代码兼容分支。
2. 轨道/DEM 几何粗配准后，用强散射点偏移估计与迭代剔除完成亚像元精配准。
3. 验收：全区和建筑密集区距离/方位残余偏移的中位数、NMAD 和 P95；目标为两方向均优于 0.1 像元，达不到则不得生成正式干涉图。
4. 构建 74 对候选网络；主分支保留 48 对，敏感性分支保留 45 对。
5. 生成干涉图、相干图和平均幅度；用 SRTM+轨道模拟并扣除平地/地形相位；按论文生成自适应滤波结果。

### C. 矢量映射与孤岛

1. 在 SRTM 地理网格上按最近邻栅格化 `Floor` 离散属性，背景为 0。
2. 用 GAMMA R-D/2D LUT 将该地面足迹属性栅格反向映射到主影像雷达坐标。这里不利用 `Floor×层高` 拉伸屋顶，也不做人工像素平移。
3. 将掩膜与平均幅度中的建筑底部二次散射亮带进行盲检：只报告几何边界距离和幅度对比，不使用楼层或最终高度优化位移。
4. 3×3 开运算、8 邻域连通分量、DBSCAN (`eps=2.5`, `MinPts=20`) 得到独立孤岛，并保存建筑 ID 对应关系和被丢弃对象清单。

### D. 独立解缠与 SBAS

1. 对每个孤岛和每个干涉对，仅把掩膜内有限像元作为节点，绝不把包围盒外的零值当观测。
2. 正文主线使用 Delaunay 邻接；边质量融合干涉相干性、时序振幅离差和 Bisquare 残差权。
3. 每个孤岛独立求整数周模糊度；种子/基准必须来自观测相位和网络连通性，不使用 `Floor` 推算高度选周。
4. 与 GAMMA 全景 MCF 解缠并行对比，复现图 3.8–3.11 所需的方向、负高程和失败次数统计。
5. 像元筛选固定为 `DA≤0.4`、全时序平均相干性 `≥0.75`，每个孤岛至少 12 个有效干涉观测。
6. 按式 (4.3)–(4.7)构建设计矩阵；以相干性构造权矩阵，WLS/SVD 联合估计平均形变速率和 DEM 高程残差。
7. 绝对屋顶高程为 SRTM 地面高程加反演残差；建筑高度为屋顶绝对高程减同建筑局部地面高程。全过程保留垂直基准一致性。
8. 单栋建筑同时冻结三个互不覆盖的字段：正文 `1.5×IQR+median`、原代码 `max-min`、稳健高度跨度 `P95-P05`。由于原代码扩展带包含地面—立面—屋顶混合像元，最终地图采用 `P95-P05` 作为不受单个极差点控制的可执行修正；无解始终保持空值。

## 6. 验收与防止“看起来像复现”

- 输入：21 日期完整、重复 ZIP 去重正确、两段拼接覆盖完整、CRC 和元数据清单可追溯。
- 几何：主裁剪尺寸和图 3.4/3.7 一致；配准残差优于 0.1 像元；LUT 无人工平移；建筑掩膜对亮带的距离分布可审计。
- 网络：明确列出 74/48/45 对及每对基线、时间、高程模糊度；图网络连通。
- 解缠：对全景 MCF 与孤岛方法使用相同输入；报告负高程/反解判据，不按先验建筑高度判断好坏。
- 反演：DA、相干性、12 对覆盖、SVD 条件数、相位残差、建筑内 IQR 均进入质量表。
- 结果：任何 `Floor` 派生高度、外部建筑高度或原代码 `max-min` 都不写入正式高度字段。
- 可复现性：所有命令由脚本生成；运行日志和软件版本入库；中间大文件不入 Git，但清单、参数、代码和摘要入库。
