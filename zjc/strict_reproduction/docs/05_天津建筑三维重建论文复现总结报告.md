# 天津建筑三维重建论文复现总结报告

**项目目录：** `zjc/strict_reproduction/`

**报告日期：** 2026-08-28

**复现对象：** 《融合 InSAR 与建筑物轮廓矢量的城市三维重建》及其原始 MATLAB；补充复现《Footprint-Constrained InSAR Phase Partitioning for High-Rise Building Height Inversion》中的非误差统计图件。

## 摘要

本项目从原始 BC3 条带模式复数 SLC 出发，重新完成天津中心城区实验区的影像导入、双条带拼接、共同区域裁剪、亚像元配准、差分干涉、SRTM 地形相位扣除、建筑轮廓雷达坐标映射、独立建筑区域构建、GAMMA-MCF 相位解缠、SBAS 速度与高程联合反演、建筑级高度汇总以及三维图件输出。整个处理链与既有同济校区实验隔离，不复用其配准结果、投影缓存或建筑高度产品。

正式处理使用 21 景 SAR 影像和 48 个差分干涉对。216 栋候选高层建筑中，198 栋获得数值解，128 栋通过冻结的内部质量门。全量成果矢量包含 126626 栋建筑，其中 126428 栋无解建筑保持空值，没有使用 `Floor`、邻近建筑或外部产品填充。正式建筑高度的 5%、25%、50%、75% 和 95% 分位数分别为 4.36、14.61、36.69、59.64 和 95.00 m。

本次工作证明了论文可由现有资料支持的处理链能够执行和审计，但不能证明论文声称的外部精度已经复现。论文使用的逐栋 LiDAR 或实测真值、79 栋人工验证建筑清单以及 GBA、CNBH-10 m 等外部产品没有随资料提供。报告因此将“流程复现”“工程修正”和“无法验证的论文结论”分别陈述，不以楼层先验代替缺失真值。

## 1. 复现目标与约束

复现工作的目标不是在既有高度图上重新绘图，而是从原始观测恢复论文方法的完整计算路径，并使每一步都能由代码、参数、日志和机器检查追溯。执行时遵守以下原则：

1. 论文正文决定方法主线，原始 MATLAB 用于恢复正文未写明的运行细节。
2. 正文、图件和代码互相冲突时，同时保留论文结果一致分支与原代码审计分支，不将二者混为同一种方法。
3. `Floor` 只可用于恢复论文候选建筑和搜索带几何，不得换算为高度后填入、校正或筛选 SBAS 结果。
4. SRTM 只用于几何定位、地形相位模拟以及地面高程基准，不作为建筑高度先验。
5. 无解建筑必须保持空值；缺失的外部高度数据和传统全景 MCF 产品不得伪造。
6. 正式图件采用独立中文 SVG，误差统计类图件按任务要求不复现。

## 2. 数据与研究区恢复

### 2.1 SAR 数据

原始数据位于 `/home/u/Downloads/中国天津市点位2`。共审计 115 个 ZIP，去重后形成 105 个逻辑产品，覆盖 2023-10-07 至 2024-06-05 的 21 个日期。每个日期选择覆盖论文中心点的相邻两段，共处理 42 个条带段。影像为降轨、左视、VV 极化、条带模式，距离向和方位向像素间距分别约为 1.249 m 和 1.791 m，雷达频率约为 5.4 GHz。

产品元数据包含部分 Sentinel/SAFE 模板字段，但实际影像不是 TOPS burst 数据。因此正式流程采用条带 SLC 导入、拼接和常规配准，没有套用 Sentinel-1 TOPS 专用步骤。

### 2.2 建筑轮廓

建筑源数据为 `zjc/天津建筑轮廓数据/天津.shp`，坐标系为 EPSG:4326，共 154051 条记录，其中 585 条为空几何。源字段 `Id` 无法作为唯一主键，复现中固定使用 `building_uid=source_fid+1`。主研究区最终写入 126626 栋有效建筑。

### 2.3 DEM 与高程基准

DEM 使用论文指定的 SRTMGL1 V003 `N39E117` 瓦片。原始 DEM 为 EGM96 正高，导入 GAMMA 时转换为 WGS84 椭球高。该转换对解释天津地区可能出现的负地面椭球高十分重要：负值表示椭球高几何关系，不代表建筑高度为负。

### 2.4 论文区域恢复

以论文中心点 117.21002778°E、39.12663889°N 和图 3.4、图 3.7 的地标布局为约束，在两段 SLC 拼接影像中冻结 10000×7000 像元的共同窗口。参考景裁剪偏移为距离向 2400 像元、方位向 10000 像元。所有日期使用同一物理窗口，避免逐景裁剪造成空间漂移。

## 3. 方法复现流程

### 3.1 条带导入、拼接与共同裁剪

每个日期的两段复数影像分别导入 GAMMA，通过重叠区相关估计距离向和方位向偏移，并校正拼接处的相位与增益差。2023-11-09 和 2023-12-12 两景的内容位置与常规序列不同，流程根据元数据和重叠相关自适应恢复裁剪位置，没有使用统一硬编码偏移。

### 3.2 亚像元配准

2023-10-07 被固定为参考景，其余 20 景生成 RSLC。配准验收门为距离向和方位向拟合标准差均小于 0.1 像元。实际距离向标准差约为 0.0064—0.0124 像元，方位向约为 0.0073—0.0151 像元，21 景复数栈全部通过验收。

### 3.3 干涉网络与差分干涉

原始候选网络包含 74 对。论文图件和结果声称使用 48 对，而正文又给出最大 44 天的时间基线阈值。两者不能同时成立，因为 48 对网络中包含 3 个 55 天干涉对。正式结果采用满足 `30 < |B⊥| ≤ 250 m` 的 48 对网络；另建立满足 `Δt≤44 d` 的 45 对敏感性网络。

每个干涉对通过 GAMMA 完成干涉、平地与 SRTM 地形相位扣除、自适应滤波和相干性估计。冻结参数为 `adf(alpha=0.4,nfft=32)` 与 `cc_wave(5×5,mode=3)`。后 38 对在 4 像元对齐的 5688×5500 子窗中处理；与全景对照的相位差和相干差均接近数值精度，因此作为不改变结果的 I/O 优化保留。

### 3.4 建筑轮廓雷达坐标映射

建筑 `building_uid` 和离散 `Floor` 属性先栅格化到地理坐标网格，再由 GAMMA R-D/二维 LUT 映射到雷达坐标。该步骤得到的是地面足迹支持域，不使用 `Floor×层高` 拉伸屋顶。

论文正文描述形态学开运算、8 邻域连通域和 DBSCAN；原 MATLAB 则对高层掩膜作不对称扩展，并整体右移 35、下移 10 像元。原代码还按写入顺序覆盖重叠建筑。为审计该差异，本项目保留两个分支：

- 字面覆盖分支包含 411725 个唯一雷达像元和 213 个建筑 ID，用于解释原 MATLAB 行为。
- 独立重叠分支保留每栋建筑自己的雷达坐标假设，即使多栋建筑共享同一像元也不互相覆盖，共包含 595973 个建筑—像元假设和 216 栋建筑，用于正式独立解缠。

### 3.5 质量筛选与建筑孤岛

21 景振幅用于计算振幅离差 `DA=σA/μA`，48 对相干图用于计算时序平均相干性。严格采用论文阈值 `DA≤0.4`、平均相干性 `≥0.75`，并要求每个像元至少具有 12 对有效观测。最终保留 25358 个高质量像元，覆盖 198/216 栋候选建筑。

### 3.6 逐建筑 GAMMA-MCF 解缠

每个干涉对、每栋建筑单独构造局部复数相位图和质量权图。权值融合单对相干性与振幅质量，并调用实际 GAMMA `mcf`，设置 `tri_mode=1`，使用 Delaunay 三角网络。48 对、216 栋建筑的解缠任务全部完成，机器汇总中的失败数为 0。

原 MATLAB 的 `unwrap_phase_matrix.m` 实际采用 9 点局部窗口、4-NN、`robustfit` 和 LSMR，并将第一点设为零，不等同于论文所述 GAMMA/Delaunay MCF。任意首像元零点会使建筑级中位数降至约 −22.5 m。正式流程改为在每栋建筑远距向 5% 边缘中选择“平均相干性×振幅质量”最高的固定参考点，并在全部干涉对中保持同一参考，不读取楼层高度。

### 3.7 SBAS 高程反演

像元相位采用两参数模型：

\[
\boldsymbol{\phi}=\mathbf{B}v+\mathbf{C}\Delta z+\boldsymbol{\varepsilon},
\qquad
C_i=\frac{4\pi B_{\perp,i}}{\lambda R_i\sin\theta_i}.
\]

其中，`v` 为平均形变速率，`Δz` 为相对固定参考像元的高程项。求解采用相干性加权 WLS/SVD，并以调谐常数 4.685 的 Bisquare 权迭代抑制残差异常值。48 对主网和 45 对敏感网独立反演，不使用 `Floor` 限制高度范围或选择整数周。

25358 个论文阈值像元全部获得解。像元高程项中位数为 24.80 m，形式高度标准差中位数为 5.34 m，相位残差 RMS 中位数为 2.79 rad。残差仍然偏大，因此“有数值解”不等于“高度准确”。

## 4. 建筑高度定义与工程修正

论文正文、原 MATLAB 与实际搜索带的物理含义存在冲突。正文规定像元高程经 1.5×IQR 剔除后取中位数；原 MATLAB 使用 `max-min`；原代码式扩展搜索带又同时包含地面、立面或叠掩、屋顶及背景候选。此时建筑内部并不是单一屋顶等高面。

为避免隐藏冲突，结果表同时保存三个字段：

| 字段 | 定义 | 用途 |
|---|---|---|
| `paper_text_median_m` | 1.5×IQR 后的中位数 | 论文正文对照 |
| `original_code_range_m` | 最大值减最小值 | 原 MATLAB 对照 |
| `robust_q95_q05_height_m` | P95 减 P05 | 扩展搜索带的稳健垂直跨度 |

正式地图字段 `recommended_building_height_m` 等于 `robust_q95_q05_height_m`。该选择保留原代码估计垂直跨度的含义，同时降低单个错误周和极端噪声点对全极差的控制。它是本项目明确披露的工程修正，不是论文原公式的字面复现。

建筑地面椭球高程在原始地面足迹内对 SRTM 取中位数，5%、50% 和 95% 分位数分别为 −4.96、−2.27 和 12.13 m。屋顶椭球高程按 `ground_ellipsoid_height_m + recommended_building_height_m` 计算。

SBAS 反演脚本不读取 `Floor`。建筑高度冻结后才单独生成 `floor_prior_posthoc_audit.csv`。正式高度与 `robust_q95_q05_height_m` 逐值相等，126428 栋无解建筑全部为 null。

后验诊断中，`Floor×3 m` 与正式高度的相关系数约为 0.44，中位绝对差约为 68.88 m。该差异没有反向用于调参、移动建筑掩膜、筛选像元或修正高度。较差的一致性说明现有纯相位链路不能支持论文级外部精度结论，也说明使用楼层先验“修正”结果会破坏独立性。

## 6. 论文与原代码差异审计

| 问题 | 论文或代码表现 | 本项目处理 |
|---|---|---|
| 数据时间 | 正文写 2023-02 至 2024-06 | 按实际 21 景使用 2023-10-07 至 2024-06-05 |
| 干涉网络 | 图件为 48 对，正文又要求不超过 44 天 | 48 对为主网，45 对为敏感网 |
| 建筑独立性 | 正文强调独立建筑区域，代码会覆盖重叠像元 | 正式分支按 `building_uid` 保留重叠假设 |
| 解缠算法 | 正文为 GAMMA/Delaunay MCF | 实际调用 GAMMA `mcf`；MATLAB LSMR 仅作对照 |
| 相位参考 | 原代码将第一像元置零 | 使用跨全部干涉对固定的远距侧高质量参考点 |
| 高度汇总 | 正文为 IQR 后中位数，代码为全极差 | 同时保存两者，正式图采用披露的 P95-P05 修正 |
| 先验高度 | 代码以楼层选择和扩展高层候选 | 只保留候选几何用途，不进入相位反演或填充 |

这些差异不是版式问题，而会改变样本数量、相位零点和建筑高度定义。因此复现报告不使用“与原文完全一致”这一表述，而采用“论文主线可执行复现并保留差异审计”。

## 10. 复现边界与未完成验证

以下内容因输入缺失而不能严格复现：

1. 论文逐栋 LiDAR 或实测建筑高度及其建筑 ID 对照；
2. 作者人工筛选的 79 栋最终验证建筑清单；
3. 论文使用版本的 GBA、CNBH-10 m 等外部产品；
4. 论文传统整幅全景 MCF 高程栅格；
5. 正文与 MATLAB 不一致时作者实际采用但未记录的人工操作。

当前反演还存在三个方法层面的限制。第一，扩展搜索带混合地面、立面、屋顶和叠掩散射，建筑高度定义依赖聚合策略。第二，固定局部参考点解决了任意零点问题，但不能完全消除独立孤岛的整数周歧义。第三，当前相位残差仍偏大，单轨、单视向数据难以为高层屋顶提供充分的外部约束。

若需进一步验证高度精度，优先级最高的新增数据是逐栋 LiDAR/测量真值、另一轨向或视向 SAR，以及更高质量的长垂直基线干涉对。新增真值应只用于最终独立检验；若用于参数选择或模糊度初始化，必须另设验证集，避免同一先验同时参与估计和评价。

## 11. 总结

本项目完成了现有材料范围内的可执行、可审计复现：从 21 景原始复数 SLC 建立 48 对差分干涉网络，完成逐建筑 GAMMA-MCF 解缠和 SBAS 高程反演，并将结果回填至全量建筑矢量。流程没有用楼层先验填充无解建筑，正式数值、原代码对照和论文正文对照均独立保存。机器检查已全部通过，28 张非误差统计类图件已按中文独立 SVG 输出。

复现的最重要结论不是“已达到论文精度”，而是明确了哪些步骤可以由原始资料重建、哪些代码行为与论文表述不一致，以及哪些外部精度结论因真值缺失仍不可验证。这一边界使后续改进能够围绕相位参考、整数周约束、屋顶散射纯度和独立真值展开，而不依赖先验高度把结果修正为预期值。
